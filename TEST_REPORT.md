# Version 6.36 validation report

The complete test suite passed: 2,967 tests, comprising all 2,924 existing tests
and 43 new font-size tests. The existing UI stub was extended to recognize
number_input. Existing test assertions were not weakened or removed.

New tests verify:
- The PDF really uses the chosen body font, including fractional sizes.
- Fixed-size mode does not shrink text when the page target is exceeded.
- Auto-fitting is opt-in and stays between the requested size and 6.5 pt.
- Rendered PDF page counts match the preflight report.
- Synthetic long-note markers survive pagination exactly once at all tested sizes.
- Text stays within page boundaries at sizes from 6.5 to 14 pt.
- Laboratory result text grows, with wider cards when necessary.
- HTML and deferred downloads receive the chosen size.
- PDF download snapshots are still isolated, revocable, and session-expiring.
- Preferences follow the user between the two print screens during a session.
- Preferences do not mutate the shared archive, drafts, or another session.
- Invalid, non-finite, boolean, and out-of-range font sizes are rejected.

The app's PDF exporter generated synthetic examples at 8, 9 and 10 pt. With the
same mapped example, the 8 pt and 9 pt handoffs each occupy one landscape page.
The 10 pt handoff occupies two pages without reducing its body font. The final
9 pt preview was rendered to a PNG and visually inspected. Earlier unmapped
variants were also inspected across both pages. No actual patient data was
used in the new preview or included in the new test fixtures.

An encrypted synthetic archive generated by the unmodified Version 6.35 code
was opened by Version 6.36 with the same key. Its fields, settings and stored
save timestamps compare equal. No archive migration is needed.

Existing runtime changes are restricted to app.py, exports.py, lab_layout.py,
and the default help in user_guide.py. The new module is print_options.py.
Clinical parsing, medication rules, encryption/storage, room reset, autosave,
BMI calculations and clinical archive schema are byte-identical to Version 6.35.
Published custom instructions are not automatically overwritten.

Interface and GitHub tests use the existing simulated widgets and mocked
responses. A live Streamlit browser session was not tested. Streamlit was not
installed in this runtime, and network restrictions prevented installing it.
No live deployment, Epic connection or private GitHub repository was accessed
or changed. This is a presentation change, not clinical validation.
