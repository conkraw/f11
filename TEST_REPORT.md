# Version 6.34 validation report

The unchanged v6.33 suite passed: 2,791 tests. The revised v6.34 suite passed:
2,884 tests, including 93 new synthetic cases. Existing assertions were updated
only where the requested bare problem names and starred-CBC defaults supersede
prior behavior. The full suite is rerun from the extracted delivery ZIP.

New coverage includes:

- wk.o. and wks.o., uppercase variants, blank lines, inline and split fields.
- A, I and N metadata imports, preserved diagnoses and under-two BMI suppression.
- Existing year/month/day formats, plus yr.o., yrs.o., mo.o. and mos.o.
- Strictly below 11.5 g/dL for asterisk-flagged hemoglobin and below 175 K/uL
  for asterisk-flagged platelets. Equality, high flagged values, missing flags,
  zero values, comparison operators, compatible units and unsupported units.
- Standard-Hgb-over-ISTAT selection, ISTAT-only fallback, newer normal results,
  excluded rows, failed sections, malformed cells and patient-specific overrides.
- Plain problem names without automatic qualifiers. Original source diagnoses,
  evidence, caution text, review state, hide/confirm choices and custom wording
  remain unchanged. No output operation automatically confirms a diagnosis.
- Text, HTML, single-room PDF, Print all PDF, encrypted round trips and unchanged
  archive schema.

The supplied A and Q patterns were transcribed from the retrieved attachment
for focused checks, not included as patient fixtures in the package. Original
v6.33 rejects the supplied week-old age syntax. v6.34 imports Age 5 wk.o. and
Sex Male correctly, removes them from diagnosis content, and does not generate
Anemia or Thrombocytopenia for the supplied unstarred normal standard counts.
The entire uploaded patient file was not exercised end to end in this update.

An encrypted synthetic archive was generated with the unmodified original
v6.33 code and opened with v6.34 using the same key. All fields, settings,
custom room data and saved timestamps compared equal. No archive migration
or new dependency is required. Older code does not understand the new age
abbreviations, so keep the current update after using those formats.

The synthetic preview was generated by the app's own PDF exporter. It contains
one landscape page at 7.2-point body text, with Age and Sex below Room, no infant
BMI, and a compact comma-separated Problems line. The rendered page was visually
inspected for clipping and placement.

Only anthropometrics.py, problem_review.py, app.py and user_guide.py changed
among runtime Python modules. CBC, blood-gas, medication, infusion, vital-sign,
feeding, device, storage, autosave, and PDF layout modules are byte-identical
to v6.33. Documentation, regression tests and synthetic examples were updated.

Tests run locally under Python 3.13. The inherited UI tests use simulations
and storage tests use mocks. No live Streamlit deployment, Epic connection,
private repository, real user session or clinical validation was tested.
No live GitHub writes were made. The configured blood-count rules are user
workflow settings, not universal age-specific diagnostic reference ranges.
