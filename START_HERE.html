PICU Handoff 6.31

Compact Problems and age-aware BMI.

Install

Save open work. Extract PICU631.zip, open PICU_Handoff_v6_31_Compact_Problems, and upload its contents into the existing code repository. Replace matching files. Keep app.py at the root, preserve all current Secrets and BMI reference data, and restart the deployment. Do not run the generators.

Problems

The printed sheet now uses a single comma-separated paragraph with an inline Problems label. Details stay in the Problems editor. Short Possible qualifiers distinguish unconfirmed inference-based conditions. The diagnoses copied from Epic are not edited.

BMI and Sex

Put Age and Sex lines in I / NUTRITION or N / admission. BMI and its percentile do not print below age 2 or when age is unknown. The source measurements stay editable. At/above 2, BMI can print and percentile calculation uses explicit age/sex with your configured CDC reference.
