PICU Handoff 6.35

Weight and height import fix.

What changed

Epic's metric height with a feet/inches equivalent in parentheses now imports without rejecting the rest of Nutrition. The printed height uses the primary recorded metric value. Genuine conflicting values still produce a warning.

Install

Save open work. Extract PICU635.zip and upload the contents of PICU_Handoff_v6_35_Weight_Import into the existing code repository. Replace matching files and keep app.py at the root. Restart and refresh. Keep current Secrets, passwords, encryption key, medication settings, private storage and public BMI reference data. Do not run the generators.

Refresh the affected handoff

Re-paste the complete I section or full SmartPhrase. Click Create / update handoff, verify the measurements, then Save handoff. Previously rejected values cannot be recovered by installing the update alone.

See WEIGHT_IMPORT_FIX.md and TEST_REPORT.md. No live deployment or private repository was tested.
