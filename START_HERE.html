PICU Handoff 6.29

Age and body measurements, dosing-weight fluid totals, latest vital readings and an Antiepileptic group.

Install

Save your open work. Extract PICU629.zip, open PICU_Handoff_v6_29_Demographics_Vitals, and upload all its contents into your existing application code repository. Keep app.py at the root. Keep all current Secrets, both passwords, encryption key, token and private data repository. Do not run the generators. Restart the deployment and refresh the browser.

New information

Add Age, Sex, BMI, Height and BSA labels to I or N, or enter them under Labs / Vitals. Re-paste the complete E section to import the new Last SpO2, Last ETCO2 and Last CVP lines. A recorded dosing weight automatically adds mL/kg to the S-section Intake and Output totals. No measured-weight fallback is used.

BMI percentile setup

The public CDC data file is not bundled. In Admin, expand BMI reference data and load the public reference, or upload the official CSV. No patient data is sent. To retain it across redeploys, store the public CSV as data/cdc_bmi_age_2022.csv in your code repository. See BMI_REFERENCE.md for the official source.

Percentiles require documented age at measurement in months (or years and months), explicit growth-chart sex and a recorded BMI. Missing inputs or reference data never generate a guessed percentile. No pediatric percentile is calculated below age 2 or at age 20 and above.

Antiepileptic group

The seven requested names are recognized automatically. Add more generic names through Admin > Antiepileptic medications. Existing exact per-order choices still win.
