PICU Handoff 6.28

Diet summaries and earliest/latest lactate results.

Update your existing app

  1. Save your current handoffs.
  2. Extract the ZIP and open PICU_Handoff_v6_28_Diet_Lactate.
  3. Upload all folder contents into your application code repository, replacing matching files. Keep app.py at the root. Include the new diet.py.
  4. Keep your existing Secrets, both passwords, encryption key, token and private data repository unchanged. Do not rerun any generator.
  5. Restart the deployment and refresh the browser. Check for Version 6.28 | Diet and lactate results.

Using the update

Paste the complete G section for laboratory updates and X for diet orders. X adds a short Diet line below intake/output in FEN/GI. PN and milk-label printing are omitted. Tube-feed details still come from T.

All supplied lactate names compete for the earliest and latest numeric result. Dates and source names stay visible. A rejected sample is not treated as a measured level. Same-day order without times is marked unverified.

Edit dietary entries under Edit handoff > FEN / GI > Edit diet / review source. Review or exclude lactate rows under Labs / Vitals.

Existing handoffs migrate automatically. No new packages are required. Do not downgrade after saving with this version.
