PICU Handoff 6.33

Last Admin infusion rates and Antiemetics.

Install

Save open work. Extract PICU633.zip and upload the contents of PICU_Handoff_v6_33_Infusion_Rates into the existing code repository. Replace matching files, keep app.py at the root, include infusion_rates.py and medication_columns.py, then restart and refresh. Keep all current Secrets, passwords, encryption key, medication settings, and public BMI reference data. Do not run the generators.

Refresh medication data

Paste the complete B section or full SmartPhrase, click Create / update handoff, then Save handoff. Older versions did not retain Last Admin values.

What changes

Explicit numeric Last Admin rates are emphasized for continuous infusions. Ordered dose ranges stay in the editor. Missing numeric rates for named or range-based titrations show UNK. Zero and non-running statuses are preserved. Ondansetron appears under Antiemetics in FEN/GI.

Existing data upgrades to archive schema 25. Do not downgrade after saving. No new Python dependency is required. See INFUSION_RATES_UPDATE.md and TEST_REPORT.md. Live hosting and private storage were not tested.
