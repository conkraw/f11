PICU Handoff 6.25

ETCO2 in respiratory vitals. CVP in cardiovascular vitals.

Install

Extract PICU625.zip, open PICU_Handoff_v6_25_ETCO2_CVP, and copy its contents to your existing application code repository. Replace matching files. Keep app.py at the root. Restart the deployment and refresh your browser.

Keep your app password, Admin password, encryption key, GitHub token and private data repository unchanged. Do not rerun either setup generator. Dependencies and saved-data format are unchanged. Installation does not clear handoffs.

Import

Select a room and paste the full SmartPhrase or complete paired E / VITALS section. Click Create / update handoff, review, then save. Include your other vital signs because E replaces the entire E-block snapshot.

These synthetic examples show the recorded minimum and maximum, not the average. Both entries appear at the top with the other vital signs, above respiratory support or infusions. No data recorded is omitted. Single labeled measurements remain supported.

Review

Use Labs / Vitals to edit or exclude a result. Source extremes remain unchanged. Missing endpoints are not filled from averages. Blood-gas PCO2 is not used as ETCO2. If a summary is ambiguous, the existing section warning remains visible and no guessed result replaces it.

Missing fields do not create placeholders. Omitting E keeps its previous snapshot. An empty or missing-data-only E clears it. Your separate notes and K/L/M neurologic observations are unchanged.
