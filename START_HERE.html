PICU HANDOFF / VERSION 6.1

Medication taper parsing fixed

This ZIP is the complete app, not a patch. No repository changes were made during this update.

Keep your existing Streamlit Secrets, password, encryption key, GitHub token and private data repository. Do not run either secrets generator again.

Update your current app

  1. Save any open handoffs and extract the ZIP.
  2. Open the PICU_Handoff_v6_1_Taper_Fix folder. Upload its contents into your existing application code repository, replacing matching files. Keep app.py at the repository root.
  3. Include all Python files, especially the new labs.py, vitals.py and lab_layout.py. Keep the existing deployment secrets unchanged.
  4. Restart the deployment, sign in and check for Version 6.1 | Medication taper parsing fix in the sidebar. Select a room and use Load medication-taper example, then Create / update handoff.

What this fixes

Epic's Followed by lines previously became an extra medication column. They are now retained as sequence labels on the next order. Each dose stays separate with its own route and frequency.

[START ON ...] dates remain visible in the editor and printed sheet. Saved medication-system mappings ignore that date prefix when matching a drug name. The app does not use the current date to decide which taper step is active.

Re-paste the full SmartPhrase and click Create / update handoff. Alternatively, paste only the paired B block to update medications. An empty C/D block is allowed and does not prevent import. Blue respiratory/lab notes are informational.

Malformed or incomplete medication rows still stop the import. This avoids silently dropping an order or guessing its dose. No claim is made that every possible Epic clipboard format is supported.

The data schema remains 6. Existing passwords, encryption keys, saved handoffs and Admin rules are preserved. No new packages are needed.

Lab trees

Paste your G block. CBC and BMP each show two result trees. Other panels show one latest value per component. Dates and flags are retained beside individual values. Blood-gas specimen types remain separate. Lactate, when present, goes to Cardiac.

The source does not provide verified same-draw panels. Values are selected per component. Same-date rows without collection times retain source order. No time, missing result or unit is invented. Read the dates beside each value.

Review or edit retained results under Labs / Vitals. Long output continues on additional landscape pages rather than clipping lab values.

Vitals at the top

Paste E to route respiratory rate and oxygenation to RESP, heart rate/BP/CVP to CARDIAC, and temperature to ID. Vitals come before support settings, notes and medications. Source ranges are preserved.

Hide and restore medications

Use Hide from handoff next to an order. It stays in Hidden medications and can be restored. The exact-formulation rule is remembered and is available in Admin. It does not hide every formulation of the same drug. The rule and the medication's system assignment are separate.

ADS Override Pull rows with blank order fields remain available instead of stopping the import. They are not filled in or hidden automatically.

Save and print

Save handoff stores the current draft. Print all prints saved rooms plus the latest open drafts. It does not itself save drafts. Each room starts on a new landscape page. Source sections absent from a paste remain unchanged.

K, L and M separators are now recognized, but SBS, WAT and ICP are not imported yet. Cultures, intake/output, nutrition and wounds also remain manual.
