PICU Handoff 6.38

Mode-specific ventilator summaries, built on the compact Version 6.37 layout.

Install

Extract PICU638.zip. Upload the contents of PICU_Handoff_v6_38_Ventilator to your existing code repository, replacing matching files. Keep app.py at the root and include ventilator_modes.py. Restart and refresh.

Keep existing Secrets, passwords, encryption key, medication mappings, private storage and CDC BMI data. Do not run the generators.

Import

Paste the full SmartPhrase or the complete paired C and D sections. Click Create / update handoff, inspect the respiratory summary, and save.

What changed

Wrapped Epic labels are recognized. PC modes show the set pressure and observed tidal volume. PRVC and VC modes show the set tidal volume. Numeric Pmin activates the Home Vent display and available pressure/time limits. Source mode names and settings remain editable.

Vt Insp prints as TVi, not TVe. Set PIP is never replaced by an observed pressure. Blank settings are omitted. Existing NIV rules and other handoff features remain available.

No numeric font picker or new dependencies. Do not downgrade after saving the new fields. See VENTILATOR_UPDATE.md and TEST_REPORT.md. The live deployment was not tested.
