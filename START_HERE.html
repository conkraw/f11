Edit and re-paste

Use Labs / Vitals for the neurologic and nutrition editors, and the respiratory editor for observed Vt. Values print above notes and medications. All values remain editable.

Paste the full SmartPhrase, or only the paired sections being changed. A supplied empty section clears its old automatic values. A missing section is left alone. Manual notes stay separate. Re-pasting does not duplicate observations. No new confirmation dialogs are added.

Existing saved handoffs

Schemas 1 through 6 migrate to schema 7 with the same key. Existing notes, medication and hidden rules, labs, vitals and respiratory values are preserved. New fields start empty until their sections are pasted. The next save uses schema 7, so replace all application files together and do not downgrade individual files after saving.
