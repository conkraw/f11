PICU SMARTPHRASE / VERSION 3

Remember mappings. Import ventilation. Print all rooms.

This is a complete update to your existing web app, not another local installation.

Keep your current Streamlit Secrets, password, encryption key and private data repository. Do not generate new secrets.

Update the app

Save your open work. Extract the ZIP and upload the contents of this folder to your existing application code repository, replacing matching files. Include the new ventilation.py, importing.py and batching.py files. Keep app.py as the entry point and reboot the deployment.

No new dependencies are needed beyond the previous medication/landscape version. Existing saved notes and mappings migrate automatically. The archive path and encryption key stay unchanged. The next successful save writes the new schema. Do not roll back only some files afterward.

Use the simplified workflow

Select a room, paste the SmartPhrase and click Create / update handoff. Diagnoses, medications and the requested ventilation block go straight into the editable draft. There are no review or replacement-confirmation checkboxes. Incomplete or conflicting input still produces an error rather than a silent partial import.

Only included A/B/C sections are updated. Other imported sections and manually entered system notes are kept. Click Save handoff to store the room's content.

Medication mappings

Choose a system beside an order in the Medications tab. That choice is immediately saved as a medication-name rule in encrypted GitHub and appears in Admin. It also updates matching orders in the open drafts and applies to future imports. The rule remembers the destination, not the dose.

Unmapped orders stay in Other Medications. Admin lets you change or remove saved rules even without an open handoff. No second Admin password or confirmation checkbox is required. A failed save is shown as an error, not as a remembered mapping.

Ventilation at the top of RESP

For the supplied supported mode, this is the automatic block, in the requested order:

Vent Mode: Volume Targeted Pressure Control - PS
Resp Rate (Set): 16
Vt (Set, mL): 160 mL
PEEP (cm H2O): 5 cm H2O
Mean Airway Pressure: 10
Insp Time (sec): 1 sec
PIP Observed (cm H2O): 24 cm H2O
Pressure Support (cm H2O): 10 cm H20
Trigger Sensitivity Flow (L/min): 0.4 L/min
FiO2 (%): 35 %
-----

Respiratory notes and medications follow the separator. No equipment, billing, heater, rise-time or minute-ventilation lines are added. Missing fields stay omitted, without substituting target tidal volume, observed rate or values from another section. Values remain editable.

BiLevel, CPAP, BiPAP and NIV labels are excluded by this display rule. Unknown modes are not guessed. The heading alone is not enough. Mode matching controls display, not clinical determination of the airway.

A valid excluded or empty C block clears the previous automatic block. A paste without C leaves it unchanged. Manual Respiratory notes and medications are preserved.

Print every handoff

Open Print all in the sidebar. All nonblank saved rooms and current drafts are selected initially. Deselect any rooms you do not need. Each room is included once, using its current draft when one exists.

Click Download all selected handoffs (PDF). Open the PDF and print it. Each room begins on a new landscape page, with continuation pages when needed. Printing does not save drafts. Save all open handoffs stores them together.

The HTML download has a Print all handoffs button when opened in a browser. PDF provides the most predictable pagination.

View the two-room synthetic PDF example or view the printable HTML example.

What remains manual

Non-invasive ventilation, vitals, cultures, labs, intake/output, nutrition and wounds are not automatically imported yet. No data is invented for those sections.

Data and deployment

The app sign-in and encrypted private GitHub archive remain. The full pasted SmartPhrase is not saved in that archive, and no external OCR or AI service is called. Successful import clears the paste field, but this is not secure erasure of server/browser memory. Downloads are unencrypted, and earlier encrypted saves remain in Git history.

Use synthetic information unless hosting and storage are institutionally approved. Omitting names and MRNs does not automatically de-identify room-linked clinical text. See README.md for storage and retention details.
