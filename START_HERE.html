PICU Handoff 6.39

Medication categories and simpler printing. Built from Version 6.38.

Install

Extract PICU639.zip. Upload the contents of PICU_Handoff_v6_39_Medication_Categories into your existing application code repository, replacing matching files. Keep app.py at the root. Restart and refresh.

Keep your current Secrets, both passwords, encryption key, medication mappings, private storage and BMI reference data. Do not run setup generators. No new dependencies are required.

Changes

New respiratory, cardiovascular and endocrine medication groups. Infusions retain their emphasized Last Admin rate within the appropriate group. Hidden orders and explicit overrides remain in effect.

Handoff downloads now offer PDF only. The routine layout-diagnostics table and pictured sidebar notice are removed. Save status and actual PDF-overflow warnings remain.

Storage wording is simpler, but encryption, access controls and storage behavior are unchanged. No re-pasting is needed for display groups.

Details

Read MEDICATION_CATEGORIES_UPDATE.md for the full medication lists and override instructions. Read TEST_REPORT.md for the validation scope. New group choices are not understood by older releases, so do not downgrade after saving them without restoring a compatible backup.
