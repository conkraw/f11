PICU Handoff 6.13

Q-section CBCs, latest ANC and ALC, and output-only removal of (Dosing Weight) from medication entries.

Update your app

  1. Save open work and extract PICU613.zip.
  2. Open PICU_Handoff_v6_13_CBC. Upload its contents into your existing code repository, replacing matching files. Keep app.py at the root. Include the new cbc.py and output_text.py.
  3. Keep your Streamlit Secrets, password, encryption key, GitHub token, mappings and private data repository unchanged. Do not rerun either secrets generator.
  4. Restart the app. The sidebar should show Version 6.13 | Q CBC, ANC / ALC and cleaner medication output.

No new dependencies. Earlier archives migrate to schema 13 with the existing key. Existing gas results and other fields stay intact. Do not downgrade partial files after saving.

Paste Q without changing the trees

Paste your full SmartPhrase or just the complete paired Q section, then click Create / update handoff. Keep all the table headers and date/time columns. The CBC drawing is retained, with the latest and preceding CBC columns. Missing values are not borrowed from another column.

Standard hemoglobin takes precedence over ISTAT. ISTAT is used only when no included standard hemoglobin exists in the supplied snapshot, and it is labelled. ANC and ALC are selected independently across automatic/manual absolute counts and print beneath the latest CBC tree with their own dates. A missing count shows --.

Review or edit

Labs / Vitals contains CBC / absolute counts. Review all retained rows, including ISTAT entries that do not print. Edit dates by column or change/exclude individual values. Old G-block CBCs remain usable until Q is supplied. Empty Q clears the automatic CBC. Omitting Q preserves it.

Blood gases remain separate

The existing latest VEN/ART/CAP selection is retained. Added compatibility covers POCT specimen-labelled rows, unlabelled PH only when one specimen is explicitly identifiable in that same column, and the No lab exists message. Conflicting or unreadable input does not replace your existing handoff.

Medication wording

Only handoff output drops the parenthetical (Dosing Weight) phrase. Source medication fields, weight-based units, mappings, held/start labels, and the demographic dosing-weight field remain unchanged.

Practice and validation

Open the synthetic practice paste or view the two-room PDF preview. The example-loading buttons remain removed. See TEST_REPORT.md for actual checks and limits. The live hosted app and private storage connection were not tested here.
