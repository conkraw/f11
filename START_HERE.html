PICU Handoff 6.41

Measurement notes and observed PIP

This package updates Version 6.40. It accepts documented height with recognized chart-transfer comments and prints observed PIP when supplied, including in PRVC and Home Vent summaries.

Install

Upload this folder's contents into your existing application code repository, replacing matching files. Keep app.py at the root. Restart the app and refresh the browser.

Keep your existing Secrets, passwords, encryption key, mappings, BMI reference data and shared storage. Do not rerun setup generators. No new dependencies or archive-format changes are required.

Refresh the affected room

Re-paste the complete I / NUTRITION section or full SmartPhrase and choose Create / update handoff. Check the measurements and choose Save handoff. A successful import clears that section's warning. Already stored observed PIP values print without re-pasting.

The sidebar should read Version 6.41 | Measurement notes and observed PIP.

Read MEASUREMENT_NOTES_PIP_UPDATE.md and TEST_REPORT.md for details.
