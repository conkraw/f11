Install

Extract PICU624.zip, open PICU_Handoff_v6_24_Feeds, and upload its contents into your current application code repository. Keep app.py at the root. Replace matching files and include the new feeds.py. Restart the deployment and refresh your browser.

Keep your app password, Admin password, encryption key, GitHub token and private data repository unchanged. Do not rerun the setup generators. Dependencies are unchanged. Installation does not clear handoffs.

Create the feeding summary

Select a room, paste the complete SmartPhrase or just the paired T section, and click Create / update handoff.

Edit and save

Open Edit handoff → FEN / GI → Edit feeds / review source. You can change method, formula or rate, and exclude or restore an entry. These edits participate in normal room saving and room-change autosave.

Omitted T keeps its prior snapshot. Included empty T clears it. A failed T does not block unrelated sections and hides previous automatic feeds until reviewed.
