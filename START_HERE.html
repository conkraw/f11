PICU Handoff 6.36

Choose your handoff font size.

Use it

In Preview / print or Print all, enter a size from 6.5 to 14 pt. Leave Allow smaller text to fit the page target unchecked to keep your chosen size. Check the page-count table before downloading.

Enable that option only when you want automatic font reduction to try a one-page or two-page target. No content is removed. Very long handoffs can still require additional pages.

Your choices follow you between rooms and Print all for this session only, without changing the shared handoffs or another teammate's preferences.

Install

Save open work. Extract PICU636.zip and upload the contents of PICU_Handoff_v6_36_Font_Size into the existing code repository. Replace matching files and keep app.py at the root. Include print_options.py. Restart and refresh. Keep current Secrets, passwords, encryption key, medication settings, private storage and public BMI reference data. Do not run the generators.

No re-pasting, new dependencies or archive conversion are needed. See FONT_SIZE_UPDATE.md and TEST_REPORT.md.
