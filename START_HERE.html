PICU Handoff 6.34

Week-old age parsing and flagged blood-count rules.

Install

Save open work. Extract PICU634.zip and upload the contents of PICU_Handoff_v6_34_Age_Problems into the existing code repository. Replace matching files and keep app.py at the root. Restart and refresh. Keep current Secrets, passwords, encryption key, medication settings, and public BMI reference data. Do not run the generators.

Refresh age and sex

Re-paste the complete A section or full SmartPhrase, click Create / update handoff, then Save handoff. Age: followed on the next line by 5 wk.o. and Sex: followed by male now work.

Problems

Names print in the existing compact Problems line, without an automatically added Possible prefix. Asterisk-flagged hemoglobin below 11.5 g/dL adds Anemia. Asterisk-flagged platelets below 175 K/uL adds Thrombocytopenia. These are clinician-configured workflow cutoffs. The editor retains source evidence and limitations, and source Diagnoses are unchanged.

No new dependencies or archive schema changes. See AGE_COUNTS_UPDATE.md and TEST_REPORT.md. Live hosting and private storage are not tested.
