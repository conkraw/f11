PICU Handoff 6.37

Built from Version 6.35. Compact printing and an optional Difficult airway tab.

Install

Save open work. Extract PICU637.zip. Upload the contents of PICU_Handoff_v6_37_Compact_Airway to your existing code repository, replacing matching files. Keep app.py at the root and include difficult_airway.py. Restart and refresh.

Keep your existing Secrets, both passwords, encryption key, medication mappings, private storage and CDC BMI reference file. Do not run the generators.

What changed

The handoff has seven columns, cleaner lab trees, NGTD culture wording, no printed import diagnostics, and an 8-point starting body font with automatic fitting. There is no numeric font picker. Published SmartPhrase date/time appears in Handoff.

Difficult airway

Open the new tab after Problems. Enable it only for a patient with a documented difficult airway, answer the questions, and save the handoff. The entered summary prints in a highlighted band at the end. With the option off, no alert prints.

Existing archives migrate without losing old fields. Do not downgrade after saving in this release. See README.md and TEST_REPORT.md. No live deployment or private storage was tested.
