PICU Handoff 6.23

Automatic PDF fitting and a one-click Admin reset.

Install

Extract PICU623.zip. Open PICU_Handoff_v6_23_Print_Reset and upload its contents to your existing app code repository. Keep app.py at the root, replace matching files, and include handoff_reset.py. Restart the deployment and refresh the browser.

Keep your app password, Admin password, encryption key, GitHub token and private data repository unchanged. Do not run the setup generators again. Installing this update does not clear handoffs.

Print fitting

Open Preview / print or Print all. Choose the default one-page target or the two-page target. The table reports the actual PDF page count per room. Content is never cropped to meet the target. Body text stays at 6.5 points or larger. Use the PDF for the exact fitted layout, because HTML printing can differ.

Clear the handoff list

Open Admin and unlock with the existing separate password. Expand Clear all handoffs and custom rooms, then click Clear all handoffs + delete custom rooms. This acts immediately without a confirmation dialog.

All current saved handoffs and this session's drafts are cleared. Custom rooms are deleted. Preset P-prefixed rooms, medication rules, hidden-medication choices, the user guide, SmartPhrase, passwords and error journal are kept.

Tell teammates to Reload saved archive after the reset. Old drafts are discarded on reload when the reset is detected. This does not erase older encrypted Git history or downloaded files.

Compatibility

No new dependencies are required. Schema 17 migrates to schema 18 without changing existing clinical records or rules. The next successful save writes the new schema. Do not downgrade after saving.
