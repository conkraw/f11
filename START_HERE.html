PICU Handoff 6.40

Neurologic medication groups and compact trends. Built from Version 6.39.

Install

Extract PICU640.zip. Upload the contents of PICU_Handoff_v6_40_Neuro_Groups into your existing application code repository, replacing matching files. Keep app.py at the root. Restart and refresh.

Keep your current Secrets, both passwords, encryption key, medication mappings, private storage and BMI reference data. Do not run setup generators. No new dependencies are required.

Changes

Observed tidal volume prints as TV. The lactate summary shows an earliest-to-latest trend with the latest date. Source fields and time-window rules are retained.

New neurologic headings: Airway/Cerebral Steroids, Insomnia, Antispasmodic and Neuromodulation. Sedative infusions, PRNs and paralytics come before the remaining alphabetical categories. Hidden medications and explicit overrides remain in effect.

Details

Read NEURO_GROUPS_UPDATE.md for grouping and override instructions. Read TEST_REPORT.md for the validation scope. No re-pasting is required for stored records. Older versions do not understand the new group choices, so do not downgrade after saving them without restoring a compatible backup.
