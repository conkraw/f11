Test the change

Select a room, click Load compact / PN example, then Create / update handoff. The synthetic example contains 18 orders, including PN followed by an And line and a separate lipid order. Use Preview / print to download the PDF.

Open the synthetic one-page print preview. Its displayed system assignments are demonstration mappings, not preloaded changes to your dictionary.

Medication fix

The standalone And connector is no longer attached as an extra column of the PN row. It remains visible on the next separate order. Both doses and rates are preserved. Mapping and hiding ignore the connector prefix. The previous Followed by fix, held labels and future start dates remain included. Re-paste the SmartPhrase that previously failed.

Compact printing

CBC and BMP still have two dated trees. LFTs, coags, blood gases and other groups now run horizontally. Different specimen groups remain separate and dates remain visible. Small print uses 7.2 pt for main text and may step down to 6.5 pt if that produces one complete page. Handwritten/editable notes are not discarded to force a fit. Oversized handoffs continue at 7.2 pt. Print all starts each room on a new landscape page.

The preview tab reports the current PDF fit and body font size. HTML is also compact but may paginate differently. Prefer the PDF for printing. Your existing saved handoffs can use the new layout immediately on export.

Existing information

There is no storage-schema change. Existing rooms, mappings, hidden medication rules, vitals, lab rows, neurologic observations, weight/Z-score and respiratory settings remain. All earlier application files are included.

Validation
