PICU HANDOFF | VERSION 6.14

Recurring orders in Labs/Imaging

Keep your existing Streamlit Secrets, password, encryption key, token and private data repository. Do not run the secrets generator again.

Update your existing app

  1. Save open work before replacing the application code.
  2. Extract the ZIP. Open the PICU_Handoff_v6_14_Labs_Imaging folder and copy its contents into your existing application code repository. Replace matching files and include the new recurring_orders.py.
  3. Keep app.py at the repository root. No dependency changes are required. Restart your existing deployment.
  4. Check the sidebar for Version 6.14 | Recurring orders in Labs/Imaging.

Use the R section

Paste the complete SmartPhrase, or only the paired R block, and click Create / update handoff. For example:

rrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrr
Orders Placed This Encounter
Procedures
• CBC and differential
    Timing: Recurring (Morning draw)
    Number of Occurrences: 5
• XR chest 1 view
    Timing: Recurring (Daily imaging)
    Number of Occurrences: 8
rrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrr

Selected repeating lab and chest X-ray orders appear automatically in Labs/Imaging. CBC/gas results stay in the existing lower result area. Existing manual Labs notes remain separate.

Selection rules

Chest X-rays, CBC, BMP, coagulation tests, magnesium, phosphorus, blood gases and lactate are included when they have a supported repeating schedule. Once, PROCEDURE ONCE, STAT, PRN and unrelated orders are omitted. CMP is not BMP and is not added by this filter.

Equivalent test and interval: the largest stated occurrence count wins. Different schedules, specimens, panels and views stay separate. Counts are source counts, not a calculation of draws remaining. Missing counts display as not listed.

Review and edit

Open the Labs/Imaging tab. Expand Edit recurring orders / review duplicates to adjust or exclude a recognized candidate. Lower-count duplicates remain accessible. Changing rooms uses the existing autosave workflow. Print all includes the same selected orders.

An omitted R section preserves existing orders. An included empty R section clears the automatic order list. Re-pasting R replaces that snapshot without changing CBCs, gases, medications or other sections.

Test without clinical records

Open examples/synthetic_recurring_orders.txt, copy its text and paste it in a practice room. This package does not add example-load buttons back to the screen. View the synthetic print preview.

Existing data and limits

The new schema adds only the recurring order snapshot. Earlier archives migrate while retaining their existing content and encryption key. Do not downgrade to older application files after saving the new schema. Source lists do not establish that all displayed encounter orders remain active.

No hosting, encryption or privacy policy changes are made by this update. Keep using your approved hosting and storage arrangements. Downloaded PDF/HTML/text exports are unencrypted. No direct repository changes were made for this ZIP delivery.
